# Docs project

A documentation project is a folder of ordinary Markdown plus a
`docs.lattice.yaml` manifest. Lattice can preview and publish through open
adapters (Starlight and others) without inventing a proprietary docs language.

## Example

```text
docs/
├── docs.lattice.yaml
├── index.md
├── guides/
├── reference/
└── assets/
```

## Status

Docs-project as a first-class in-app resource is **near-roadmap**. The folder
layout above is the intended public contract; see the format support matrix.
