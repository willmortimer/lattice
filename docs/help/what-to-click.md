# What to click

Ignore advanced panels until you need them. Day one is these surfaces:

| Place | What it is for |
| --- | --- |
| **Left tree** | Browse the real folder |
| **Main area** | Edit or view whatever you opened |
| **⌘/Ctrl+P** | Create something or jump by name |
| **⌘/Ctrl+K** | Search inside this workspace |
| **Inspect** | Details for the thing you already have open (links, history, schema) |

You do not need a separate “power user mode.” When something needs more detail,
open **Inspect** on that item.
