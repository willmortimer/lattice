# Find things

| Need | Do this |
| --- | --- |
| Open or create by name | **⌘/Ctrl+P** |
| Search text in the workspace | **⌘/Ctrl+K** |
| Browse by folder | Use the left tree |

Search only covers the workspace you have open — not every folder on your Mac.
