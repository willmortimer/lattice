# Open a workspace

A workspace is just a folder. Lattice shows that folder as your file tree.

## Do this

1. Open Lattice.
2. Create a new workspace, or choose **Open workspace…** for an existing folder.
3. Confirm you see files and folders in the left tree.

## Quick check

Write a short page, then open the same folder in Finder. You should see a
`.md` file. If you do, Lattice is using real files — that is the point. Select
that file and press **Space** to preview it as formatted Markdown.

## Shortcuts you will use constantly

| Want | Press |
| --- | --- |
| Create or jump | ⌘/Ctrl+P |
| Quick note | ⌘/Ctrl+N |
| Search | ⌘/Ctrl+K |
| Screen clip to inbox | ⌘⇧2 |

Use the **robot** button on the left rail when you want the workspace agent
beside your files.
