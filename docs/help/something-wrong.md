# Something looks wrong

Try these in order before assuming data loss.

| Symptom | Try |
| --- | --- |
| Cannot find a file you know exists | Confirm the correct workspace folder is open |
| Edits disappeared | Check whether another app had the file open; look in **Inspect → History** |
| Banner about an external or stale change | Reload / accept the newer version instead of saving over it |
| Search misses obvious text | Wait a moment for indexing, or reopen the workspace |
| Table or dataset looks empty | You may be on a filtered view — clear filters in the view picker |
| App feels stuck on a heavy file | Close the tab; reopen; prefer Import for huge CSVs rather than previewing as a giant page |

Still stuck? Note what you clicked and open the
[troubleshooting guide](https://lattice-notes.com/docs/troubleshooting/) online,
or check **Inspect** on the resource that misbehaved.
