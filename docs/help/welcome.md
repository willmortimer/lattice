# Welcome to Lattice

Lattice is an app for notes, boards, and tables that live in a **normal folder**
on your computer — not locked inside a private cloud document.

## Start with three actions

1. Open or create a workspace folder.
2. Press **⌘/Ctrl+P** to create a page (or jump to one).
3. Press **⌘/Ctrl+K** when you need to search.

That is enough to be useful. Use the Help sidebar for “what do I click?” topics.
For longer guides and technical reference, open the
[docs site](https://lattice-notes.com/docs/) when you are online.
