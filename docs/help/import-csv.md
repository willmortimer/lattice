# Import a spreadsheet

Use this when you have a CSV (or similar) and want a real editable table inside
the workspace — not just a file sitting in the tree.

## Do this

1. Press **⌘/Ctrl+P**.
2. Choose **Import table…** (wording may say Import CSV).
3. Pick the file.
4. Check the column types Lattice guessed, then confirm.
5. Open the new table from the tree and edit cells like a spreadsheet grid.

## After import

- Switch layouts (grid, list, board…) from the view picker when you want a
  different look at the same rows.
- Use **Inspect** on the table if you need schema or history.

Still only need to glance at a file once? Leave it as an ordinary file — you do
not have to import everything.
