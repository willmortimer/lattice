# Write a page

1. Press **⌘/Ctrl+P**.
2. Choose **New page** (or type a title and create).
3. Type in the main area. Lattice saves as you go; **⌘/Ctrl+S** saves now.

## Useful while writing

- Type `[[` to link another page in this workspace.
- Type `/` for block inserts when you want a heading, list, or similar.
- Press **⌘/Ctrl+N** for a quick capture note when you are mid-flow.

Your page is a Markdown file in the folder. Other editors can open it too.
