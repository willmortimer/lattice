# Roadmap

The structured roadmap lives in `Product/Roadmap.data`. Open **Product pulse**
for the recording view, or switch among the roadmap, features, feedback, and
decisions tables for the underlying records.

## Shipped foundation

- Pages, search, quick capture, canvas and local voice.
- SQLite data applications with relations, formulas, rollups, forms, actions
  and interfaces.
- Local Hive Parquet through DuckDB, bounded Arrow IPC, Perspective, Vega-Lite,
  Profile, Plan, Cancel and point maps.
- Notebooks, artifacts, tasks, workflows, proposals and derived resources.
- Known-workspace scheduling and the governed inspect → propose → approve loop.

## Active edge

- Embedded agent Phase A is experimental.
- GitHub connected roots are read-only and in progress in this checkout.
- Cloud share, publish, backup and MCP endpoints are experimental backend APIs.

## Next product increments

1. Remote Parquet with explicit network authority, secrets, streaming batches,
   progress and cache policy.
2. Deeper connected-repository metadata and governed writeback.
3. Cross-filtered BI, semantic models and full GeoParquet.
4. Presentation bookmarks, ordered scenes and connected publishing.
